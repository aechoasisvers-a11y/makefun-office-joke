One line about office life: the printer that only ever jams when something is due meets the one document that has no deadline at all. The setup is a trope every office worker knows, the turn is the resignation printing without a hitch, and the punchline lands last in a single breath.

> "Our printer only jams on deadline day, so I printed my resignation — not a single jam." (86 characters)

It fits the brief because it is a real joke with a setup and a turn, it turns on the universally recognised deadline-day printer jam, it surprises instead of complaining plainly, every word earns its place — the punchline even answers the setup in the printer's own word, "jam" — and the twist, quitting as the only print job the printer respects, is not the version already going round the office.
